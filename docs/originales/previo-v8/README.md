# Archivo anterior al HTA v8

Documentos conservados sin modificaciones durante la adopción de la v8. Describen decisiones o interfaces anteriores y no son entregables vigentes. Las menciones a actividades anteriores se conservan como historia, no como alcance actual.

La referencia vigente es [HTA de correo y vocabulario v8](../../../HTA_correo_vocabulario_v8.pdf). La correspondencia actual está en [Revisión y trazabilidad](../../REVISION_HTA_Y_TRAZABILIDAD.md).

`manifest.json` registra las rutas originales y los SHA-256 de los once archivos conservados. Los enlaces relativos internos de las copias históricas no se han reescrito para preservar sus contenidos. La matriz de principios original permanece en la raíz como fuente de comparación; no describe el alcance de tareas vigente.
