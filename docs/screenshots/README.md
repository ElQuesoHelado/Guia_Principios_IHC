# Evidencias visuales

Las capturas vigentes del rediseño conversacional están en `actual/`, generadas por `tools/generate_screenshots.py`. Los PNG de esta carpeta y de `principles/` pertenecen a la interfaz anterior y se conservan como material histórico; no son evidencia de la implementación actual.

La ampliación del 26/11/2026 incluye `14_expresiones.png` (significado y estructura de asuntos), `15_razon_finalidad_movil.png` (apoyo lingüístico dentro del chat móvil) y `16_sugerencia_ingles.png` (sugerencia contextual mientras se escribe). Las capturas muestran escenarios preparados; no acreditan aprendizaje ni evaluación con usuarios.

`17_ejemplos_separados.png` muestra los grupos de ejemplos de correo y vocabulario. La guía basada en la matriz la referencia al explicar C3.4 (agrupar contenido similar) y C8.5 (rastro de información).
